# Skill

The first version of the Copilot skill will live here. It will guide the user and run the PowerShell CLI.

The skill should be thin:

- It should not implement OBS, FFmpeg, or Whisper logic itself.
- It should run scripts from `scripts\`.
- It should interpret error messages and help the user move forward.
- It should support a guided app-review flow.

Implementation will be added next.
